Neles Nugget – PWA

Dateien:
- index.html: die Quick-Reference
- manifest.webmanifest: App-Name, Farben und Icons
- sw.js: Offline-Cache
- icon-192.png / icon-512.png: App-Icons

Wichtig:
Eine PWA muss über HTTPS (oder localhost) ausgeliefert werden.
Für GitHub Pages alle Dateien in die oberste Ebene eines Repositorys hochladen.
